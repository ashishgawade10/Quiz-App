# Quiz Application 🧠

A simple and interactive Quiz Application built using HTML, CSS, and JavaScript.

## 🚀 Features

- Multiple choice questions
- Answer selection
- Correct and wrong answer indication
- Score calculation
- Next question navigation
- Clean responsive design

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
